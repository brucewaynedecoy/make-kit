# Phase 2: Register, Index, Glossary and Other Owners

## Purpose

This phase changes the Make Blueprint register and the shared PRD surfaces, and the few other PRDs that repeat a shared rule: 00, 02, 03, 04, 10, 17 and 18. The register items keep their numbers. The [overview](00-overview.md) holds the owner questions that the new register items record.

## Rules for This Phase

- Use the decision meanings and the link form in [Phase 1](01-prd-links.md#rules-for-this-phase). A root link from `docs/prd/` has four `../` steps.
- Never renumber a register item. Keep each item's table, fields and accepted text. Add an `**Update (2026-11-01)**` paragraph where an accepted decision now has a root owner, as the register already does for Q-077.
- Use only the status values `Open`, `Confirming`, `Deferred` and `Closed`.
- Change no heading text. Root PRDs link to the register items Q-024, Q-060, Q-072, Q-077, D-011, O-001, R-001 and R-002 by heading.
- Write in ASD-STE100 Simplified Technical English. Use no semantic line breaks.
